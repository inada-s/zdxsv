プライバシーポリシー

制定日: 2026年11月12日

zdxsv.net (以下「zdxsv」) は、PlayStation2版 機動戦士ガンダム ガンダムvs.Zガンダム の非公式通信対戦サーバーです。このページでは、zdxsv のサーバー、このウェブサイト、PCSX2 for zdxsv が扱う利用者の情報について説明します。

1. 取得する情報

Discord でのサインイン (PCSX2)

  • Discord のユーザー ID

サインインのとき、Discord にはアカウントの確認に必要な最小限の権限だけを求めます。Discord のパスワードやメールアドレスは zdxsv に渡りません。ユーザー名やアバターも Discord から届きますが、保存しません。

アカウントと対戦

  • ゲームのログイン ID、ユーザー ID、ハンドルネーム、チーム名
  • アカウントの作成日時、最後にログインした日時
  • 戦績 (対戦数、勝敗、撃墜数など) と対戦ごとの記録 (対戦相手、使用機体、結果)
  • 対戦のリプレイ

接続の情報

  • IP アドレス (アカウントを作ったとき、最後にログインしたとき、サーバーのログ)
  • PCSX2 の場合: PC を識別する情報

PCSX2 のクラッシュレポート

PCSX2 for zdxsv が異常終了したとき、クラッシュレポートを開発者に送ります。内容はクラッシュ時のメモリの一部、設定ファイル (PCSX2.ini)、直前のログ、OS の種類、ランダムなインストール ID、送信元の IP アドレスです。設定 > zdxsv で送信をオフにできます。

取得しないもの

ロビーや対戦中のチャットの内容は保存しません。

2. 利用目的

  • サインインとログインの認証、通信対戦の提供
  • 戦績、ランキング、リプレイの提供
  • 不正行為や迷惑行為への対応 (利用制限を含みます)
  • 障害の調査とサービスの改善

3. 公開される情報

  • このウェブサイトの「接続情報」に、ロビーと対戦中の利用者のユーザー ID とハンドルネームが表示されます
  • 戦績、対戦の記録、リプレイは、ユーザー ID とハンドルネームとともに公開されることがあります

4. 外部のサービス

zdxsv は次のサービスを使います。利用者の情報を販売したり、広告に使ったりすることはありません。

  • Discord: サインイン
  • Google Cloud: サーバーのログ、データベースのバックアップ、リプレイの保存
  • Sentry: PCSX2 のクラッシュレポート
  • GitHub: このウェブサイトと PCSX2 for zdxsv の配布

法令に基づく場合を除き、これ以外の第三者に利用者の情報を提供しません。

5. 保存期間

アカウント、戦績、リプレイは、zdxsv を提供している間保存します。サーバーのログは、障害の調査に必要な期間だけ保存します。

6. Discord との連携の解除

  • Discord との連携は、Discord の ユーザー設定 > 認証済みアプリ でいつでも解除できます。PCSX2 の 設定 > zdxsv の「サインアウト」で、その PC のサインイン情報をサーバーから無効にできます
  • zdxsv に保存された Discord のユーザー ID の削除を希望する場合は、Discord サーバー のサポートチャンネルでご連絡ください

7. このポリシーの変更

このポリシーは必要に応じて変更します。変更した場合はこのページでお知らせします。
