基本情報

Playstation2版 機動戦士ガンダム ガンダムvs.Zガンダム の非公式通信対戦サーバーです。

※公式の通信対戦サービスは2011年6月30日に終了しています。非公式サーバーに関するお問い合わせは絶対しないでください。

PS2 実機での接続方法と UDPプロキシの使い方は PS2 をご覧ください。
PC (PCSX2) で遊ぶ方法は PCSX2 をご覧ください。
対戦の募集やボイスチャットは Discord を使用します。使い方は こちらをご覧ください。

PS2 で遊ぶ

PlayStation2 実機 (又は初期型 PlayStation3) で接続する方法です。PC で遊ぶ場合は PCSX2 をご覧ください。

必要なもの

  • PlayStation2本体 又は 初期型PlayStation3本体
  • PlayStation2版 機動戦士ガンダム ガンダムvs.Zガンダム
  • メモリーカード
  • コントローラー
  • ネットワークアダプタ(薄型本体なら不要)

接続設定

  1. PlayStation2とルーターをLANケーブルで接続しゲームを起動
  2. 通信対戦 > ブロードバンド接続 > ネットワーク接続 > ネットワーク設定の編集 を選択
  3. 環境に応じて設定を作成する 基本は「自動設定する」でOK
  4. DNSサーバーの設定で「自動設定しない」を選択
  5. プライマリDNSに 153.121.44.150 を入力 セカンダリDNSは 0.0.0.0 でOK
  6. 設定を保存
  7. 通信対戦 > ブロードバンド接続 > ネットワーク接続
  8. 上で作った設定を選択
  9. サーバーTOPが表示されたら成功

登録・ログイン

  1. 注意事項を熟読
  2. 「新規登録」を選択 (初回のみ)
  3. 「ログインIDとパスワードを記録する」を選択
  4. サーバーTOPに戻り「ログイン」を選択 (2回目以降はそのままログインでOK)
  5. カプコンユーザー登録/変更は「登録しない」を選択
  6. HNを決定し戦場選択画面へ

UDPプロキシ (PS2 向け)

概要

対戦中の通信方式を変換することによって、対戦中のラグを軽減します。

対戦中の通信は、TCPという通信方式が使われています。TCPは高機能ですが、ゲームのようなリアルタイム通信には向いていません。

UDPという低機能でリアルタイムな通信に向いている通信方式に変換することで、ラグを軽減することができます。変換は間にPCを挟んで行います。

必要なもの

  • PS2と同じネットワーク(ルーター)に接続しているPC(有線接続推奨)
  • プロキシソフト zproxy
zproxy をダウンロード GitHub Releases から zdxsv_<版>_<OS>_<CPU>.zip を選んでください 他の OS / CPU 版はこちら (GitHub Releases)

zip を解凍して中の zproxy (Windows は zproxy.exe) を実行してください。起動時に新しい版があれば自動で更新されます。

使い方

  1. サーバーにログインしてロビーに接続しておきます
  2. PCでプロキシソフトを起動し、登録ボタンを押します
  3. プロキシソフトの画面に「登録成功 <ログインしているZのユーザーID>」が表示されればOK
  4. 初めての場合は接続テストを行ってください
  5. 対戦中にPCがスリープや再起動しないようにしておいてください

接続テスト

  • UDPプロキシをつけた状態で、ケネディポートのロビー自動選抜に参加すると、PC-PS2間の接続テストができます
  • 一人対戦が始まれば、テストは成功です

アンチウイルスソフトの例外設定

接続テストが上手く行かない場合、アンチウイルスソフトによって通信がブロックされている可能性があります。

zproxyを例外ソフトとして登録することで回避ができます。やり方は各アンチウイルスソフトごとに異なるので、設定の仕方を調べてください。

参考: セキュリティソフトの設定 | オンライン麻雀 Maru-Jan 公式サイト

初回起動時の注意(Windows)

※他のアプリケーションで安全であるかわからない場合には、実行しないようにしましょう。

起動時に以下のような警告が出た場合、詳細情報をクリックし、実行を押します。

セキュリティの警告が出た場合、赤枠のところにもチェックを入れて、アクセスを許可するを選択してください。

PCSX2 で遊ぶ

PC 上のエミュレーター PCSX2 で接続する方法です。PS2 実機で遊ぶ場合は PS2 をご覧ください。

必要なもの

  • Windows (64bit) の PC
  • PS2 の BIOS (PS2 本体から吸い出したもの)
  • PlayStation2版 機動戦士ガンダム ガンダムvs.Zガンダム
  • Discord アカウント (ログインに使います)
  • コントローラー
  • PCSX2 for zdxsv
PCSX2 for zdxsv をダウンロード (Windows 64bit) pcsx2-zdxsv-windows-x64.zip (最新版) 最新版のリリースページ (GitHub Releases)

使い方

  1. zip を解凍して中の pcsx2-qt.exe を実行します
  2. 初回起動時のセットアップで BIOS とゲームの場所を設定します
  3. セットアップの「zdxsv アカウント」で「Discord でサインイン」を押します。ブラウザに「ZDXSV にログイン」の画面が開くので、「Discord でログイン」を押し、Discord の画面で認証してください。終わったら PCSX2 に戻ります
  4. ゲームを起動し、通信対戦を選択します

セットアップでログインしなかった場合は、あとから 設定 > zdxsv でログインできます。

PS2 のアカウントを引き継ぐ

PS2 で遊んでいるアカウントを、PCSX2 でも使えます。PS2 では引き続き同じアカウントで遊べます。対戦数が 100 以上のアカウントが対象です。

  1. PS2 でケネディポートのロビーに入ります
  2. チャットで ｄｃ (全角) と入力すると、引き継ぎコードが表示されます
  3. 3分以内に、PCSX2 の 設定 > zdxsv >「PS2 から引き継ぐ...」でコードを入力します
